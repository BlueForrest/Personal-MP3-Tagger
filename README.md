# Personal-MP3-Tagger
Personal MP3 tagger

build in python with the help of AI.

Runs within a docker container on my ZIMA-OS server.

It's created to correct my MP3 tags for my own personal needs, like lookup, year, lyrics, YT video, comments ... from different sources and pick the most relevant one.
