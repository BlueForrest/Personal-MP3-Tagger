# Personal-MP3-Tagger
jstal-tagger:
_______________________________________________________________
Build in python with the help of different (all free) AI-tools.

Runs within a docker container on my ZIMA-OS server.

It's created to correct my MP3 tags for my own personal needs, like lookup, year, lyrics, YT video, comments ... from different sources and picks the most relevant one.
